ATV02-DW-REACT
Projeto feito com React e Next.js que consome a PokeAPI, uma API pública de Pokémon. Na tela principal aparece uma lista de cards com os nomes dos pokémons, e ao clicar em qualquer um deles abre um modal com mais detalhes como altura, peso, tipos e habilidades.
Para rodar o projeto, basta instalar as dependências com npm install e iniciar com npm run dev. Depois é só acessar http://localhost:3000 no navegador.
